# Российские инженерные навыки для ChatGPT и Codex

Публичный плагин с 22 навыками для российской проектной и сметной документации: сметы, ГГЭ/XML, МЧРГ, газоснабжение, пояснительные записки, титульные листы и штампы, DWG, PDF, DOCX, XLSX, 1С и Яндекс Трекер.

## Подключение в ChatGPT Work

Администратор рабочего пространства добавляет этот GitHub-репозиторий как marketplace:

`https://github.com/dmarkovby-afk/russian-engineering-skills`

После синхронизации установите плагин **Российские инженерные навыки**. В его составе ChatGPT увидит все каталоги из `plugins/russian-engineering-skills/skills/`.

## Структура

- `.agents/plugins/marketplace.json` — каталог для импорта из GitHub;
- `plugins/russian-engineering-skills/plugin.json` — переносимый манифест Agent Plugins;
- `plugins/russian-engineering-skills/.codex-plugin/plugin.json` — совместимый манифест Codex;
- `plugins/russian-engineering-skills/skills/` — навыки.

## Ограничение публичной версии

В публичный пакет намеренно не включены рабочие PDF, DOCX, XLSX, DWG и изображения из приватного архива. Это предотвращает публикацию клиентских документов, подписей, штампов и шаблонов конкретных объектов. Для задач, требующих таких материалов, пользователь должен приложить собственные исходники или использовать свою разрешённую локальную копию шаблона.

Плагин не содержит MCP-серверов, OAuth-настроек, ключей API или токенов.

## Обновления

Новые каталоги навыков появляются внутри этого же плагина после публикации очередной версии репозитория и синхронизации marketplace в ChatGPT Work.
