# Обязательная матрица формул МЧРГ

Перед расчетом сопоставить эту матрицу со структурой зафиксированного шаблона. Каждую применимую строку закрыть формулой, обозначениями, единицами, подстановкой и результатом.

| Блок | Обязательное содержание |
|---|---|
| Тепловой баланс | Сумма отопления, вентиляции, ГВС и потерь: `QΣ = Qот + Qв + Qгвс + Qпот`. |
| Перевод мощности | `N = QΣ × 1,163`, МВт. |
| Часовой расход по нагрузке | `Вч.нагр = QΣ × 10⁶ / (Qн.ккал × η)`, м³/ч. |
| Перевод теплоты сгорания | При формуле с МВт: `Qн.МДж = Qн.ккал × 4,1868 / 1000`, МДж/м³. |
| Часовой расход по мощности | `Вч.мощ = n × P × 3600 / (Qн.МДж × η)`, м³/ч. |
| Паспортный расход | `Вч.пасп = количество оборудования × паспортный расход единицы`, м³/ч. |
| Выбор МЧРГ | `Вч.расч = max(Вч.нагр; Вч.мощ; Вч.пасп)`. |
| Годовой отпуск тепла | Формулы по отоплению, вентиляции, ГВС и потерям; затем `Qгод = ΣQi.год`. |
| Условное топливо | `Ву.т = Qгод / (7 × η) × 10⁻³`, тыс. т у.т./год. |
| Годовой природный газ | `Вгод = Qгод × 10⁶ / (Qн.ккал × η)`, м³/год. |
| Помесячный расчет | Формулы помесячного тепла и `Vм = Qм × 10⁶ / (Qн.ккал × η)`; сумма месяцев равна годовому итогу с учетом округления. |
| Резервирование | Для II категории показать отключаемые нагрузки, мощность оставшегося оборудования и долю обеспеченной аварийной нагрузки, %. |

## Контроль единиц

- В формуле с `3600` мощность задавать в МВт, а низшую теплоту сгорания — в МДж/м³.
- В формуле с `10⁶` тепловую нагрузку задавать в Гкал/ч или Гкал/год, а низшую теплоту сгорания — в ккал/м³.
- Не подставлять значение в Гкал/ч в позицию мощности МВт.
- Не смешивать полезную тепловую мощность, тепловую нагрузку и паспортный расход газа.
- Проверять арифметику независимо от ГСН, ТУ, паспорта и прежнего расчета.

## Выпускной критерий

Расчет готов только после успешного запуска `scripts/audit_formula_completeness.py` с ожидаемым МЧРГ. При пропуске любого блока исправить документ либо, если мешает неизменяемый шаблон, запросить разрешение пользователя на конкретное изменение структуры.
