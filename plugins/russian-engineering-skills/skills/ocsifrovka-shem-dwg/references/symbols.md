# Каталог УГО

Точка вставки — на оси трубы, в геометрическом центре корпуса (для манометра — точка отбора). Локальная ось 0° — вдоль +X.

Размер по умолчанию подобран для листа A3. Если на фото символ крупнее или мельче соседних — менять `scale` или `attrs.size`.

## Арматура (`layer` FITTINGS)

| type | Что на схеме | Геометрия | rotation |
|---|---|---|---|
| `valve_ball` | кран шаровой | два треугольника вершинами друг к другу | вдоль трубы |
| `valve_gate` | задвижка | два треугольника + шток вверх в локальных координатах | вдоль трубы |
| `valve_globe` | вентиль | два треугольника + тёмный кружок в центре | вдоль трубы |
| `valve_check` | обратный клапан | треугольник + седло (поперечная черта) | остриё по потоку |
| `valve_thermal` | клапан термозапорный, КТЗ | кран + буква T / перекладина на штоке | вдоль трубы |
| `valve_safety` | ПСК, предохранительный | угловой клапан вверх | 0 = сброс в +Y после поворота |
| `filter_gas` | фильтр газовый | ромб (квадрат 45°) с крестом внутри | вдоль трубы |
| `reducer` | переход ДуA-B | два усечённых контура, сужение в +X | узкий конец в +X при 0° |
| `flange` | фланец, соединение | две короткие засечки поперёк оси | вдоль трубы |
| `cap` | заглушка | поперечная черта и короткие усики | торец в +X |
| `regulator` | регулятор давления, РДБК | корпус как вентиль + прямоугольник привода сверху | вдоль трубы |
| `meter_gas` | счётчик газа | окружность с внутренней окружностью | центр на оси |
| `vent` | газопродувочная свеча | стояк, треугольник сверху, штриховка у основания | 0 = стояк в +Y |

## КИП (`layer` INSTR)

| type | Что на схеме | Геометрия | rotation |
|---|---|---|---|
| `manometer` | манометр МТИ, МПТИ | отвод от оси + окружность с стрелкой | 90 = вверх от горизонтальной трубы |
| `manometer_diff` | дифманометр ДМ | два отвода и окружность | как манометр |

## Поток

| type | Назначение |
|---|---|
| `arrows[]` в сцене, не symbol | стрелка на трубе; не путать с блоком |

## attrs

Частые ключи:

- `size` — характерный габарит, мм (клапан/фильтр/счётчик).
- `stem` — длина штока/отвода манометра, мм.
- `dn1`, `dn2` — для `reducer`, только справочно, на контур влияет `size`.

Если нужного УГО нет, не собирать «почти клапан» из десяти линий: добавить ближайший тип и дорисовать отличие одним-двумя `primitives`, либо расширить `scripts/pid_symbols.py` тем же именем `type`.

## Как ставить на трубу

1. Найти точку на полилинии трубы, где стоит символ.
2. `pos` = эта точка.
3. `rotation` = угол сегмента трубы в градусах.
4. Текст марки — отдельный `texts[]` рядом, не атрибут блока (кроме случаев, когда на исходнике текст внутри символа).
