# Схема выгрузки `.sm`

Файл `.sm` этой программы является базой Microsoft Access/Jet.

## Основные таблицы

### `ReportHead`

- `NumberSm` — внутренний номер сметы.
- `Stroika` — наименование объекта, по которому подтверждается цель изменения.

### `TRascenkiFull`

Основная таблица строк сметы.

- `Kod` — уникальный внутренний код строки; использовать значение выше текущего максимума.
- `NumberSm` — связь со сметой.
- `Rascenka` — видимый код, не более 16 символов.
- `Rabota`, `EdIzm`, `Volume` — наименование, единица и количество.
- `PrZatrOb`, `MaterOb` — цена единицы ручного материала.
- `Order` — порядок отображения.
- `manualcalc=True` — колонка «Запр. пересчет», защищает ручную позицию от автоматического пересчета по нормативной базе.
- `ExcludeRasc=False` — позиция включена в расчет.

### `TVibMater`

Ресурсы, которые используют материальные печатные формы.

- `NumberSm`, `KodRascenki` — связь с `TRascenkiFull.NumberSm` и `TRascenkiFull.Kod`.
- `Material` — тот же видимый код, что `Rascenka`.
- `Name`, `EdIzm`, `Volume`, `Norma` — реквизиты и количество.
- `Price91`, `Stoim91` — базовые цена и сумма.
- `FaktPrice`, `FaktStoim` — фактические цена и сумма.
- `OtklPrice` — сохраненная ручная цена.
- `NDS`, `WithNDS` — ставка и сумма с НДС.
- `b_price_manual=True` — ручная цена ресурса.

## Почему нужна пара таблиц

Одна строка только в `TRascenkiFull` дает сумму в смете, но печатная форма может показать пустую расшифровку. Одна строка только в `TNewTovar` не становится отдельной строкой основной сметы. Для ручного материала нужна связанная пара `TRascenkiFull` + `TVibMater`.
