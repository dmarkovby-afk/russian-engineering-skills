# Формат материалов

Сохранить файл в UTF-8 как массив объектов:

```json
[
  {
    "name": "Обратный клапан 3/4",
    "unit": "шт",
    "quantity": 1,
    "unit_price": 24.53,
    "amount": 24.53
  },
  {
    "name": "Труба",
    "unit": "м",
    "quantity": 7,
    "unit_price": 1.92,
    "amount": 13.44,
    "code": "MAT-236-002"
  }
]
```

Обязательные поля:

- `name` — наименование без перефразирования;
- `unit` — единица измерения;
- `quantity` — положительное количество;
- `unit_price` — цена за единицу без НДС.

Необязательные поля:

- `amount` — сумма строки; если задана, скрипт проверяет арифметику;
- `code` — видимый код расценки до 16 символов. При отсутствии скрипт формирует код из `CodePrefix`.
