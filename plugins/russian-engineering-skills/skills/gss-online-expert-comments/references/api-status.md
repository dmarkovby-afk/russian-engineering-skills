# Статус API ГОССТРОЙСМЕТА-онлайн

Проверено 14.09.2026 по официальному публичному сайту и руководству пользователя.

## Вывод

Публичный поддерживаемый API для загрузки, редактирования, пересчёта и экспорта ЛСР, ОСР, ССРСС и ВОР не обнаружен. Официальное руководство описывает эти операции через веб-интерфейс и обмен файлами GGE/XML/Excel/PDF.

После авторизации подтверждено, что веб-приложение технически использует внутренний JSON API с маршрутами семейства `/api1/` и передаёт токен сессии в заголовке `Authorization`. В клиенте видны, в частности, операции получения сведений о файлах и папках, а также внутренние конвертеры GGE в редактор ЛСР. Клиент содержит отдельные редакторы `localestimate`, `objectestimate`, `summaryestimate` и `workvolume`.

Это доказывает техническое наличие внутреннего API приложения, но не право и не устойчивую возможность использовать его как интеграционный API. В публичном клиенте и официальных материалах не найдены Swagger/OpenAPI, правила выдачи интеграционных ключей, гарантии совместимости, лимиты и условия поддержки. Стандартная библиотека Bitrix REST на внешней странице также не является таким подтверждением.

Практический вывод: автоматизация без браузера потенциально возможна только после официального подтверждения поставщика либо получения документированной спецификации. Использование токена браузерной сессии и воспроизведение закрытых AJAX-запросов не считать допустимым рабочим решением.

## Правило выбора канала

1. Повторно проверить официальный сайт, руководство, договор/тариф и сведения, предоставленные поддержкой. В личном кабинете раздел поддержки позволяет создать обращение; отправлять его только по прямому запросу пользователя.
2. Если пользователь предоставляет официальную спецификацию API, изучить методы, авторизацию, лимиты, версии схем и среду; выполнить сначала только безопасные операции чтения.
3. Для записи использовать API лишь после подтверждения целевых документов и резервного копирования исходников. Секреты не сохранять в файлах навыка и не выводить в отчёты.
4. При отсутствии официальной спецификации не копировать приватные AJAX-запросы, cookies и токены браузера и не выдавать их за API.
5. Использовать гибридный маршрут: локальный программный разбор и проверка GGE/XML; браузер только для функций сервиса — импорт, редактор, пересчёт, встроенная экспертиза и экспорт.

## Что запросить у поставщика для перехода на API

- базовый URL и OpenAPI/Swagger либо полное описание методов;
- поддерживаемые типы документов и версии схем GGE;
- способ авторизации и порядок выдачи ключа;
- методы загрузки, проверки, редактирования, пересчёта связей и экспорта;
- ограничения тарифа, размеры файлов, частоту запросов и журналирование;
- тестовый контур и правила обработки конфиденциальной документации.
